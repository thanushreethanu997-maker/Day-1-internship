# Personal Information Program

## Description
A simple Python program that collects basic
user information and displays it as a formatted profile.

## Requirements
- Python 3

## Inputs
- Name
- Age
- City
- Course
- College name
- Email

## Output
Displays the entered information in a
clean and formatted profile.

## Concepts Used
- Variables
- input()
- print()
- Type conversion using int()
- f-strings

## How to Run
Run the following command:

python personal_info.py
